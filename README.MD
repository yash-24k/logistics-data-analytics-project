# Logistics Data Analytics Project

A 4-week data analytics project applying Python to logistics challenges, using the DataCo Smart Supply Chain Dataset.

## Project Structure
- **Week 1:** Strategic planning — scenario definition, KPIs, and proposed data science approach
- **Week 2:** Data collection, cleaning, and preprocessing (missing values, outliers, normalization)
- **Week 3:** Exploratory data analysis and visualization (histograms, bar charts, correlation heatmap)
- **Week 4:** Predictive modeling (Linear Regression) and optimization recommendations

## Tools Used
Python, pandas, scikit-learn, matplotlib, seaborn
